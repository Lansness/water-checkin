# 一起喝水 🐳

一个和朋友一起喝水打卡的小网站。记录每天喝了多少毫升，日/周/月统计，还有一个朋友之间的排行榜。

> 本仓库只包含代码。演示站点是私人部署的，地址不在此公开。

第一次进入填个名字、挑个形象就能开始，不需要注册、不需要密码。

## 功能

**我的记录**
- 快捷项一键记录：`1 壶 1.5L` / `1 保温杯 500ml` / `1 瓶装水 550ml` / `1 纸杯 200ml`（可自己增删改）
- 自定义毫升数，并可写**备注**说明这口是什么（比如「运动后补水」）
- 今日明细流水，每条带时间，可单独撤销
- 可以补录以前某天的记录
- 我的日 / 周 / 月统计：合计、日均、达标天数、达标率、连续达标天数

**排行榜**
- 今日榜 / 本周榜 / 本月榜，另外还有一个连续达标榜
- 每行显示名次、形象、昵称、数值、进度条、是否达标
- 前三名金银铜配色，自己那一行高亮

## 本地运行

这个页面**必须由 HTTP 服务提供**，直接双击用 `file://` 打开是不行的。

原因是云服务按域名做 Origin 校验，`file://` 和 `127.0.0.1` 都会被拒绝，页面只会显示一条「读不到云端数据」的提示。这是预期行为，不是坏了。

想在自己的机器上跑：

```bash
# 1. 复制配置模板，填入自己的云服务信息
cp config.example.js config.js

# 2. 起一个静态服务器
python -m http.server 8000

# 3. 浏览器打开 http://localhost:8000
```

注意 `localhost` 同样会被云服务的 Origin 校验拦下。**要看到真实数据，只能通过已经发布出去的正式域名访问。**

## 配置

`config.js` —— 本地使用，**已被 `.gitignore` 排除**，不会进仓库：

```js
window.WATER_CLOUD = {
  endpoint: "https://你的应用域名.app.workbuddy.host",
  oauthRelayBaseUrl: "https://www.workbuddy.cn/v2/as/genie-baas/oauth",
  publishableKey: "wbpk_..."
};
```

`config.example.js` 是提交进仓库的模板，克隆后复制成 `config.js` 即可。

`publishableKey` 是给浏览器用的公开密钥（页面上任何人查看源代码都能看到），但它绑定具体的应用，所以单独放一个文件、不提交，避免别人克隆后误连到我的数据库。

## 数据怎么存的

后端用的是 WorkBuddy 云服务（数据库 + 托管），两张表：

| 表 | 字段 | 作用 |
|---|---|---|
| `players` | `device_key`、`nickname`、`role`、`goal`、`presets` | 参与者及其目标、快捷项 |
| `entries` | `device_key`、`day`、`amount`、`label`、`created_at` | 饮水流水 |

**身份**：第一次进入时浏览器本地生成一个随机 `device_key` 存进 `localStorage`，它才是真正的身份标识；昵称和形象只是展示用的名字。

**为什么不能删除记录**：`entries` 表在数据库的授权层面只有 `INSERT` 和 `SELECT`，**没有 `UPDATE` 也没有 `DELETE`**，连权限策略都没有建。所以任何人（包括记录者自己）都改不了、删不掉已经写下的流水。

「撤销」的实现是**追加一条负数金额**：

```
11:03   1 壶           1,500 ml
11:40   撤销：1 壶     −1,500 ml
```

原始记录永远留着，账对得上。撤销三天前的记录，那条负数也会落在三天前那一天。

**排行榜**是前端把数据拉下来自己聚合的，朋友数量不多，够用且简单。

## 技术栈

- 单个 `index.html`，零构建步骤，零依赖打包
- 图表是手写的 SVG（连图表库都没有），所以断网也能渲染
- 云端 SDK 通过 CDN 引入，主源 jsdelivr，失败自动切 unpkg
- 数据全部走一个 `api` 适配层，方便替换数据源

## 已知限制

- **换设备或清浏览器缓存 = 变成新用户。** 身份密钥存在 `localStorage` 里，丢了就找不回来。不过「加入」时有「之前用过？直接选自己」的入口，可以认回已有身份。
- **没有真正的登录**，服务端无法识别你是谁。昵称设了唯一约束，能挡住顺手占用，但挡不住存心冒充；昵称和形象也可能被他人改。
- **应用地址是固定的**，云服务按域名精确校验，换域名会让鉴权失效。

这几条都是「不要密码」这个取舍的必然代价。
